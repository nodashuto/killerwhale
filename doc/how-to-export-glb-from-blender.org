*Apply All transformation*: In object mode, Press ~Ctrl+A~ and select "Apply all transformations".

*Join*: Select all objects and ~Ctrl+J~ to Join all objects together.

*Convert to Mesh*: In Object Mode, open Object Tab > Convert > Mesh



This video is highly informative and everything you need to know is here basically.  [[https://www.youtube.com/watch?v=JuVfA3V3DVU][How To Get A Collider From A Map/Model (GLTF OR GLB) In Bevy Using Rapier]] 



Exported file can store transformation data. 
data  (transformation, rotation and  scales) defined in blender are to be dropped when we import and convert mesh data to collider in Bevy/Rapier.
By "Apply all transformations", we can aligh mesh and collider at same position.
