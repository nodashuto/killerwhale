# Killerwhale Engine

My 3d game engine in Rust, Bevy.


<a id="org5b97725"></a>

## Requirements

-   Rust `1.96.1`
-   bevy `0.19.0`
-   bevy rapier3d `0.35.0`

Game physics and collision are based on bevy rapier3d.
